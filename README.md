# Don-t-touch
I made a little project which is help to prevent thief broke into houses like the door locks are made with metals so i use it as grounding source of my project.I create this project with transistor and touch module so basically when someone touch the metal lock he grounded the circuit and completed it an alarm turn on it also has a reset button to turn the alarm off .
and a litle step while you building the project in th project wou need to scratch a little part of the touch sensore and connect a wire it with the door lock ,or any metal surface.
