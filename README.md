# Don-t-touch
i made a little project which can prevent thief from broke into your house . it's really basic project i didn't use any microcontroler ir ic in this project

<img width="590" height="278" alt="Screenshot 2026-05-03 222616" src="https://github.com/user-attachments/assets/983e679c-cf38-4f1a-a44d-9a15d89554e6" />

it can really useful for those people who's doors are really silent . in my project i use a TTP223 touch sensore . when someone touch the door metal part it instantly Triger the buzzer it even have reset button to stop the alarm.
to build this project you need all the components and pcb given in my BOM and pcb after getting all those parts you simpely need to solder everything on place and then scratch a little part on touch sensor and solder a wire wich connect to a metal part of your door metal part and turn on the switch that's all.
